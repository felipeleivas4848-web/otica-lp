LOGOS DAS ÓTICAS — seção "Resultados no mercado óptico" (seção 08)
==================================================================

Coloque nesta pasta os arquivos de logo com EXATAMENTE estes nomes:

  oticas-diniz.jpg
  oticas-carol.jpg
  mercadao-dos-oculos.jpg
  oticas-gassi.jpg

(Para trocar por PNG/SVG, ajuste a extensão na tag <img> em index.html.)

Recomendações
-------------
- Formato: PNG com fundo transparente (ou SVG).
- As logos aparecem dentro de um "chip" branco, então logos escuras
  ou coloridas funcionam bem. Logo totalmente branca não vai aparecer.
- Altura útil ~30 px; largura até ~150 px. Pode mandar em resolução
  maior (ex.: 300 px de altura) que o CSS reduz.
- Se usar SVG, troque a extensão no index.html de ".png" para ".svg"
  na tag <img> correspondente.

Enquanto o arquivo não existir, o chip da logo some sozinho e fica
só o nome da ótica em texto (nada quebra).
